# 沙盒宪法（Constitution）

> spec-kit `.specify/memory/constitution.md` 的最小手搓版。
> 真实项目里这份由 `/speckit.constitution` 生成，并被每个 `/speckit.*` 命令引用。

## 原则
1. **门控优先**：任何任务未通过验收测试，不得标记 `[x]` 完成。
2. **验收独立**：实现者不得给自己打分；验收由独立上下文的 subagent 依据 spec 的验收标准判定。
3. **最小改动**：一次只动当前任务相关的代码。
4. **测试先行**：每个功能任务都必须有对应的 pytest 断言作为客观门控。
5. **人类红线**：架构、支付、密钥类决策不进循环，遇到标 `- [!]` 交人拍板。

## 两层门控
- **硬门控 `gate.sh`**：lint + 可导入 + 测试可收集（代码没坏）。
- **任务验收**：该任务专属测试（`pytest -k ...`）变绿 + 独立 subagent 确认。
