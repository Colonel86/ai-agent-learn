# 向量相似度与归一化

> 场景：RAG / 语义搜索中比较两个 embedding 向量的相似程度。

---

## 一、向量相似度比较的常用方法

### 1. 余弦相似度（Cosine Similarity）⭐ 最常用

只看方向、忽略长度，对 embedding 比较最常用。

```python
from numpy import dot
from numpy.linalg import norm

cos_sim = dot(e1, e2) / (norm(e1) * norm(e2))

# 或使用 sklearn
from sklearn.metrics.pairwise import cosine_similarity
cosine_similarity([e1], [e2])
```

- **与点积的区别**：点积同时受向量长度影响；余弦相似度做了归一化，只衡量"方向接近度"。
- **取值范围**：[-1, 1]，1 表示完全同向。

> 注：OpenAI / 大多数现代 embedding 模型输出的是**已归一化**向量（模长=1），此时 **点积 = 余弦相似度**，所以你会看到很多代码直接用 `np.dot`。

### 2. 欧氏距离（Euclidean / L2 Distance）

衡量两点在空间中的直线距离，**越小越相似**。

```python
np.linalg.norm(e1 - e2)
```

适合：物理空间含义明确的场景；不适合高维稀疏向量。

### 3. 曼哈顿距离（L1 Distance）

```python
np.sum(np.abs(e1 - e2))
```

对异常值更鲁棒，但语义场景下用得少。

### 4. 点积（Dot Product）

```python
np.dot(e1, e2)
```

计算最快。**向量已归一化时**等价于余弦相似度，是生产环境向量检索（FAISS、Milvus）默认指标之一。

### 5. Jaccard 相似度

用于集合 / 稀疏二值向量（如 BoW、关键词集合），不适合稠密 embedding。

### 选型建议

| 场景 | 推荐 |
|---|---|
| 语义 embedding（OpenAI / BGE / sentence-transformers） | **余弦相似度** 或 已归一化后用点积 |
| 向量数据库高性能检索 | **点积**（先归一化） |
| 低维、有物理意义的特征 | 欧氏距离 |
| 集合 / 关键词重叠 | Jaccard |

**经验法则**：做 RAG / 语义搜索，无脑选余弦相似度；追求性能就先 L2 归一化再用点积。

## 二、归一化（Normalization）是什么

简单说：**把向量的"长度"缩放到 1，只保留方向信息**。

### 直观理解

想象一个箭头：
- **方向**：指向哪里（语义信息）
- **长度（模长）**：箭头多长（数值大小）

归一化 = 把所有箭头都拉伸 / 压缩到**长度为 1**，但方向不变。

### 数学公式

```
归一化向量 = 原向量 / 原向量的模长
```

向量的"模长"（length / norm）：

$$\|v\| = \sqrt{v_1^2 + v_2^2 + \dots + v_n^2}$$

### 举个例子

```python
import numpy as np

v = np.array([3, 4])

# 模长 = √(3² + 4²) = √25 = 5
length = np.linalg.norm(v)   # 5.0

# 归一化后
v_normalized = v / length     # [0.6, 0.8]

# 验证：归一化后模长 = 1
np.linalg.norm(v_normalized)  # 1.0
```

向量 `[3, 4]` 和 `[6, 8]` **方向相同**，归一化后都是 `[0.6, 0.8]`。

### 为什么要归一化

**点积**会同时受方向和长度影响：

```python
a = [1, 0]
b = [1, 0]      # 跟 a 完全同向
c = [100, 0]    # 跟 a 也完全同向，只是更长

np.dot(a, b)  # = 1
np.dot(a, c)  # = 100   ← 数值大，但其实方向一样！
```

这就有问题了——**我们想比较"语义相似度"，不关心向量本身有多长**。

归一化之后：

```
a, b, c 都变成 [1, 0]
点积都 = 1   ✓ 公平比较
```

### 与余弦相似度的关系

余弦相似度公式：

$$\cos\theta = \frac{a \cdot b}{\|a\| \cdot \|b\|}$$

**等价于**：先把 a、b 都归一化，再做点积。

所以：

> **归一化后的向量做点积 = 余弦相似度**

这就是为什么 OpenAI 文档说他们的 embedding 已经归一化了，可以直接用 `np.dot()` —— 因为此时点积就等于余弦相似度，但计算更快（省掉了除以模长那一步）。

### 一行代码归一化

```python
v_normalized = v / np.linalg.norm(v)
```

## 三、关键术语速查

| 术语 | 英文 | 一句话解释 |
|---|---|---|
| 嵌入向量 | Embedding | 把文本/图片映射到的高维数值向量，承载语义 |
| 点积 | Dot Product | 对应位相乘再相加，受方向和长度共同影响 |
| 模长 / 范数 | Norm / Magnitude | 向量的"长度"，记作 \|\|v\|\| |
| 归一化 | Normalization | 把向量缩放到模长为 1，只保留方向 |
| 余弦相似度 | Cosine Similarity | 衡量两向量方向接近度，[-1, 1] |
| 欧氏距离 | Euclidean / L2 Distance | 两点直线距离，越小越相似 |
