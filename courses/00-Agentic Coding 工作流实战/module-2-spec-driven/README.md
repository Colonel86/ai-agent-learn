# Module 2 · Spec-Driven Development with Coding Agents

- **合作方**：JetBrains（讲师 Paul Everitt）
- **课程链接**：https://www.deeplearning.ai/courses/spec-driven-development-with-coding-agents/
- **在本课程中的角色**：方法论——从"凭感觉"到"有规范"

## 学习重点

- 项目宪法（Constitution）：长期原则与约束
- 功能规范（Spec）：单功能的明确意图
- **Plan → Implement → Verify** 三段式工作流
- 在遗留代码上应用 SDD
- 把工作流封装为可复用 Skill（与课程 16 衔接）
