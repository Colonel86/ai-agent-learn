本节构建课程的压轴项目——一个多节点的**论文写作智能体**，综合运用了前几节的所有概念。

---

**系统架构**

```
入口 → [规划] → [初始研究] → [生成草稿] → 条件判断
                                              ↓ 继续
                                           [反思批评]
                                              ↓
                                           [批评研究]
                                              ↓
                                           [生成草稿] → 循环...
                                              ↓ 达到最大修订次数
                                             END
```

---

**状态设计（比之前复杂得多）**

```python
class AgentState(TypedDict):
    task: str           # 用户输入的写作主题
    plan: str           # 规划节点生成的大纲
    draft: str          # 当前草稿
    critique: str       # 反思节点的批评意见
    content: list[str]  # Tavily 搜索到的文档列表（operator.add 追加）
    revision_number: int    # 当前修订次数
    max_revisions: int      # 最大修订次数上限
```

---

**五个节点 + 一个条件判断**

**规划节点**：用规划提示词 + 用户任务 → 生成大纲，更新 `plan`

**初始研究节点**：用 `model.with_structured_output(Queries)` 基于任务生成搜索词列表 → 调用 Tavily → 追加到 `content`

**生成节点**：将任务、大纲、所有搜索文档组合输入写作 LLM → 更新 `draft`，`revision_number + 1`

**反思节点**：将草稿输入批评 LLM → 更新 `critique`

**批评研究节点**：基于批评意见生成新搜索词 → 调用 Tavily → 追加到 `content`

**条件判断（`should_continue`）**：`revision_number >= max_revisions` → END，否则 → reflect

---

**演示效果**

任务：LangChain 与 LangSmith 的区别（GPT-3.5 训练数据中没有这两者）

执行流程：
1. 生成写作大纲
2. 搜索相关资料
3. 写出第一稿
4. 批评：建议深化优劣势分析
5. 基于批评再次搜索
6. 写出第二稿（最终版）

---

**图形界面（GUI）演示**

GUI 展示了人工介入的实际应用：

- 在任意节点后设置**中断点**，逐步审查每个阶段的输出
- 暂停后可**修改状态**（如将大纲改为"果冻甜甜圈在披萨制作中的重要性"）
- 发现方向不对，可**时间旅行**回到原始规划状态重新来过
- 支持**多线程**并发：同时写两篇不同主题的论文，各自独立的状态历史
