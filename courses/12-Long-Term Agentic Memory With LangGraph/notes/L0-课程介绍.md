## 一、课程定位

> **学习如何给 AI Agent 添加"长期记忆"——让它跨多次对话、跨多个会话持续学习和成长。**

这是 DeepLearning.AI × LangChain 的合作课程。

---

## 二、为什么需要 Agent 的长期记忆？

### 2.1 现状

> **越来越多的 AI 应用需要"跨时间持续运行"**——不再是一次性问答，而是长期陪伴用户。

### 2.2 典型场景：AI 个人助理

| 场景 | 没有长期记忆 | 有长期记忆 |
|------|--------------|-----------|
| 每次对话 | 像第一次见面的陌生人 | 越用越懂你 |
| 会议安排 | 每次都问偏好 | 自动按你的习惯安排 |
| 邮件回复 | 千篇一律 | 模仿你的语气和风格 |

> 💡 **Andrew 的观察**：助理类应用是长期记忆**最自然的落地场景**。

---

## 三、长期记忆的两个核心难题

### 3.1 问题 1：**存什么**（What to Store）

> Chatbot 时代只需要保留对话历史——但 Agent 需要决定**哪些信息值得长期保留**。
>
> 例子：日历 Agent 需要记住"我和 X 总在周三下午开会"这种**跨多次调用都有用**的信息。

### 3.2 问题 2：**取什么**（What to Retrieve）

> 检索时把**记忆里的相关片段**塞进上下文。
>
> 还要决定**何时更新**记忆：
> - **Hot path**（每轮对话即时更新）
> - **Background**（后台异步更新）

---

## 四、记忆的三大分类

> 这是本课程的**核心心智模型**——把记忆按类型分开，方便分别管理。

| 类型 | 英文 | 本质 | 例子 |
|------|------|------|------|
| **语义记忆** | Semantic Memory | 事实 / 知识 | 用户重要的生日、产品规格 |
| **情景记忆** | Episodic Memory | 经历 / 案例 | 这位用户上次怎么做某事的 |
| **程序记忆** | Procedural Memory | 规则 / 行为指令 | "处理邮件时应该 ..." 这类规则 |

## 五、新工具：LangMem 库

> **LangChain 团队为本课程发布的新库**，专门处理 Agent 长期记忆。

### 核心能力

- ✅ 接入**向量数据库**做语义检索
- ✅ **可搜索**（searchable）
- ✅ **可共享**（shareable，多 Agent 间共享同一份记忆）
- ✅ **持久化存储**（persistent storage）
- ✅ 双模式更新：**Agent 即时更新** 或 **Helper Agent 后台异步更新**
