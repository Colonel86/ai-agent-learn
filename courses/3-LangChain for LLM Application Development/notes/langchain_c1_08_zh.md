# LangChain for LLM Application Development — 第08课：课程总结（中文字幕）

---

在这门短期课程中，你看到了一系列应用，包括：

- 处理客户评论
- 构建基于文档的问答应用
- 使用 LLM 决定何时调用外部工具（如网络搜索）来回答复杂问题

---

## 回顾

如果在一两周前有人问你，构建所有这些应用需要多少工作量？我想很多人会回答："哇，这听起来需要好几周，甚至更长时间。"

但你在这门短期课程中看到了，只需**相当合理数量的代码行数**，就能用 LangChain 高效地构建所有这些应用。

---

## 展望与鼓励

我希望你能把这些想法带走，甚至把你在 Jupyter Notebook 中看到的一些代码片段用到你自己的应用中。

这些想法只是一个开始。语言模型能做的事情还有很多：

- **查询 CSV 文件中的数据**
- **查询 SQL 数据库**
- **与各种 API 交互**

LangChain 中有大量关于如何使用链、提示词与输出解析器的组合来完成这些任务的示例，而这大多要归功于 **LangChain 社区**。

我也想向所有做出贡献的社区成员表示衷心感谢——无论是改进文档让新人更容易上手，还是开发新类型的链，开拓了全新的可能性。

---

## 行动号召

如果你还没有这样做，我希望你现在就打开电脑，运行：

```bash
pip install langchain
```

然后用这个工具去构建一些了不起的应用吧！
