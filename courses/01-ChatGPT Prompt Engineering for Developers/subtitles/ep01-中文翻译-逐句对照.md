在大语言模型（LLM）的发展中，大致有两类 LLM，我将它们称为 **Base LLM** 和 **Instruction-tuned LLM**。

**Base LLM** 被训练为基于文本训练数据来预测下一个词，通常在来自互联网和其他来源的大量数据上训练，以弄清最可能跟在后面的下一个词是什么。所以举个例子，如果你给它输入"Once upon a time there was a unicorn"（从前有一只独角兽），它可能会补全为"that lived in a magical forest with all her unicorn friends"（住在一片魔法森林里，和所有独角兽朋友在一起）。

但如果你给它输入"What is the capital of France"（法国的首都是什么），那么基于互联网上的文章内容，Base LLM 很可能会补全为"What is France's largest city, what is France's population"（法国最大的城市是什么，法国的人口是多少）等等，因为互联网上的文章很可能是关于法国的测验题列表。

相比之下，**Instruction-tuned LLM**——这也是 LLM 研究和实践的主要发展方向——已经被训练为遵循指令。所以如果你问它"法国的首都是什么"，它更可能输出类似于"法国的首都是巴黎"这样的内容。

Instruction-tuned LLM 的典型训练方式是：先从一个在大量文本数据上训练过的 Base LLM 开始，然后进一步训练它——用指令和遵循这些指令的良好尝试作为输入输出来做进一步微调——之后通常还会用一种叫做 **RLHF**（Reinforcement Learning from Human Feedback，基于人类反馈的强化学习）的技术进行进一步优化，使系统更好地提供帮助并遵循指令。

因为 Instruction-tuned LLM 被训练为 **helpful（有帮助的）、honest（诚实的）和 harmless（无害的）**，所以它们比 Base LLM 更不可能输出有问题的文本（比如有毒内容），大量实际使用场景已经转向了 Instruction-tuned LLM。你在网上找到的一些最佳实践可能更适合 Base LLM，但对于今天的大多数实际应用，我们建议大多数人转而关注 Instruction-tuned LLM——它们更容易使用，而且由于 OpenAI 和其他 LLM 公司的工作，它们变得更安全、更对齐。

所以这门课程将聚焦于 Instruction-tuned LLM 的最佳实践，这也是我们建议你在大多数应用中使用的。

所以，当你使用 Instruction-tuned LLM 时，可以把它想象成**给另一个人下指令**——一个很聪明但不了解你任务细节的人。所以当 LLM 不好用时，有时是因为指令不够清晰。比如，如果你说"请帮我写一些关于 Alan Turing 的东西"，那还不够——明确说明你是希望文本聚焦于他的**科学工作**、还是他的**个人生活**、还是他在**历史中的角色**或者其他方面，会更有帮助。如果你能指定你想要的文本**语气**——应该像专业记者写的那样，还是更像你随手给朋友写的便条？——这能帮助 LLM 生成你想要的内容。

当然，如果你想象自己正在要求一个**刚毕业的大学生**来执行这项任务，如果你甚至能指定他们应该提前阅读哪些文字片段来写关于 Alan Turing 的文字，那就能更好地帮助这个刚毕业的大学生成功完成你交给的任务。
