---

**目标：构建一个 arXiv 论文搜索聊天机器人**

使用的库：arxiv SDK、json、os、typing、Anthropic SDK。

**两个核心函数**

`search_papers(topic, max_results=5)`：在 arXiv 上搜索论文，将结果（ID、标题、摘要、PDF 链接等）保存到本地 `papers/papers_info.json` 文件，并返回论文 ID 列表。

`extract_info(paper_id)`：根据论文 ID 从本地 JSON 文件中读取详细信息，找不到则返回提示字符串。

**将函数封装为工具**

按照 Anthropic 工具使用的格式，为每个函数定义包含名称、描述和参数 Schema 的工具对象。模型本身不会直接调用函数——需要开发者编写代码，在检测到模型请求调用工具时，调用对应函数并将结果返回给模型。

**聊天循环逻辑**

1. 维护消息历史，将用户输入添加到消息列表
2. 调用 Claude 模型（示例中使用 claude-3-7-sonnet）
3. 若响应为文本，直接输出
4. 若响应为工具调用，执行对应函数，将结果追加到消息历史，再次调用模型
5. 输入 "quit" 退出循环

**演示效果**

- 输入"搜索代数相关论文"→ 模型自动调用 `search_papers` 工具，返回论文 ID 列表
- 输入"提取前两篇论文的信息并总结"→ 模型调用 `extract_info` 工具，返回标题、摘要、PDF 链接等信息

注意：本聊天机器人没有持久化记忆，每次对话都是全新开始，使用时需手动传入之前获取的论文 ID。
