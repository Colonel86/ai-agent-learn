让我们来看一些 Agentic AI 应用的实例。

**发票处理**

许多企业都需要处理发票。给定一张发票，你可能需要编写软件来提取关键字段，比如开票方、开票方地址、应付金额和到期日。在很多财务部门，这项工作通常由人工完成。如果用 Agentic 工作流来实现，流程可能是这样的：输入发票后，调用 PDF 转文本 API 将其转换为 LLM 可读取的格式（如 Markdown），然后由 LLM 判断这是否是一张发票，如果是，则提取所需字段，并调用工具将关键信息写入数据库。这类有明确流程可循的任务，往往更容易用 Agentic 工作流来实现，因为它能以相对逐步、可靠的方式完成。

**客户订单查询智能体**

稍复杂一些的例子是构建一个处理基本客户订单查询的智能体。步骤可能包括：提取关键信息（客户姓名、订单内容），查询相关客户记录，然后起草回复邮件供人工审核后再发送。同样，流程清晰，易于逐步实现。这类客户订单查询智能体如今已在许多企业中得到部署。

**通用客服智能体**

更具挑战性的例子是构建一个能回答任意客户问题的通用客服智能体。比如客户问"你们有黑色或蓝色牛仔裤吗？"，就需要多次调用数据库 API 分别查询库存，再综合回复。或者客户说"我想退货我买的沙滩巾"，则需要核实购买记录、检查退货政策，如果允许退货，就生成退货单并更新数据库状态。在这种情况下，所需步骤事先不可知，LLM 必须自行规划执行顺序，难度更高，结果也更难预测。

**计算机操控智能体**

最后一个例子难度最大：让智能体直接操控网页浏览器来完成复杂任务。在演示中，Andrew 让智能体查询联合航空两个特定航班是否有空位。智能体能够自主浏览联合航空网站、点击页面元素、填写表单；当联合航空网站出现问题时，它还能主动切换到 Google Flights 搜索，再返回联合航空网站确认结果。计算机操控是目前极具前沿性的研究领域，但实际应用中智能体在使用浏览器时仍时常出错——例如遇到加载缓慢的页面就可能失去判断，许多网页仍超出智能体的准确解读能力。尽管如此，这依然是一个充满潜力的重要发展方向。

**难易程度总结**

以下情况往往让 Agentic 任务**更容易**实现：
- 有明确的步骤流程或标准操作规程可循
- 只需处理纯文本输入

以下情况则往往让任务**更具挑战**：
- 所需步骤事先未知，智能体需要边做边规划
- 需要处理声音、图像、音频等富媒体多模态输入
