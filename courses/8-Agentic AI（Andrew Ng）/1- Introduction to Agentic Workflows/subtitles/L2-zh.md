那么，什么是 Agentic AI，为什么 Agentic AI 工作流如此强大？让我们来看一看。

今天，我们很多人使用大语言模型（LLM）的方式是这样的：给它一个提示，让它就某个主题 X 写一篇文章。我把这比作去找一个人——或者在这里是去找一个 AI——让它从第一个字写到最后一个字，一气呵成，中间从不按退格键。

事实上，我们人类在被迫以这种完全线性的方式写作时，并不能写出最好的作品，AI 模型也是如此。尽管如此，在这种限制下，我们的 LLM 表现得出奇地好。

相比之下，Agentic 工作流的过程可能是这样的：先让它就某个主题写一个文章大纲，然后询问是否需要做一些网络搜索，搜索并下载一些网页后，再写出初稿，然后阅读初稿，看哪些部分需要修改或补充研究，再进行修改，如此循环。这种工作流更类似于先思考、再研究、再修改、再思考的过程。通过这种迭代，Agentic 工作流虽然耗时更长，但最终交付的成果质量要好得多。

所以，**Agentic AI 工作流**就是一个基于 LLM 的应用通过执行多个步骤来完成任务的过程。在这个例子中，你可能先用一个 LLM 写出文章大纲，再用一个 LLM 决定要在搜索引擎中输入什么关键词，从而获取相关网页。然后将下载的网页输入 LLM 让它写出初稿，再用另一个 LLM 进行反思并决定哪些地方需要修改。根据你的工作流设计，甚至可以加入一个"人工介入"环节，让 LLM 可以请求人工审核某些关键信息，再据此修改草稿。这一过程最终会产出质量更高的结果。

这门课程的核心技能之一，就是学会如何将"写一篇文章"这样复杂的任务分解为更小的步骤，让 Agentic 工作流逐步执行，最终得到你想要的输出。知道如何分解任务、如何构建各个步骤的执行组件，是一项复杂但至关重要的技能，它将决定你能否为各种令人兴奋的应用构建 Agentic 工作流。

在这门课程中，我们将以一个**研究智能体**作为贯穿始终的示例，你将和我一起亲手构建它。比如，你可以输入一个研究主题："我如何创办一家新的火箭公司来与 SpaceX 竞争？"——我个人并不想与 SpaceX 竞争，但如果你有兴趣，可以让研究智能体帮你做背景调研。

这个智能体会先规划需要使用哪些研究资源，包括调用网络搜索引擎下载网页，然后对发现的内容进行综合和排序，起草大纲，让一个编辑智能体检查逻辑连贯性，最后生成一份完整的 Markdown 报告。这份报告包含引言、背景、发现等章节，并恰如其分地指出，这将是一个极难创建的初创公司。

通过搜集和下载多个来源并进行深度思考，这份报告要比直接让 LLM 写文章所得到的结果深思熟虑得多。我之所以对此感到兴奋，是因为在我的工作中，我已经构建了相当多的专业研究智能体，涵盖法律合规文件、医疗健康领域以及商业产品研究等方向。我希望通过这个示例，你不仅能学会如何为其他各类应用构建 Agentic 工作流，同时，如果你将来需要构建自定义研究智能体，这些经验也能直接派上用场。
