## 本周核心要点速览

### 1. Agentic 不是二元的，是一个谱
- 自主性从**低**（硬编码流程）→ **高**（LLM 自主决定步骤）→ **极高**（能创造新工具）。
- 大量高价值应用都在**低自主**端。

### 2. Agentic 工作流三大优势
- **性能**：许多任务表现远超直接生成（甚至能让弱模型超过强模型）。
- **并行化**：人类必须串行的任务可并行执行。
- **模块化**：工具和模型可插拔。

### 3. 构建智能体的核心技能
| 技能 | 含义 |
|---|---|
| **任务分解** | 拆成可被 LLM 或工具执行的离散步骤 |
| **Evals** | 端到端 + 组件级；客观用代码，主观用 LLM-as-Judge |
| **Error Analysis** | 读 trace，找可改进处 |
| **迭代** | 先跑，看结果，再分解 / 改工具 / 改提示 |

### 4. 四大设计模式
1. **Reflection（反思）** —— 让 LLM 审查并改进自己的输出。
2. **Tool Use（工具使用）** —— 让 LLM 调用 web 搜索、代码执行、数据库等。
3. **Planning（规划）** —— LLM 自主决定步骤序列。
4. **Multi-Agent Collaboration（多智能体协作）** —— 多角色 agent 协作完成复杂任务。

### 5. 最大的成功预测因子
> **严谨的 evaluation（评估）流程。** 不是模型选择，不是 prompt 工程，是围绕 evals 和 error analysis 的开发纪律。
