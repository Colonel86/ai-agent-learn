# L6 课程总结（Conclusion）

整门课走过的内容回顾。

## 五个模块的脉络

### Module 1：Agentic AI 概览

讨论 Agentic AI 能解决哪些**之前做不到**的应用——给出整体可能性图景。

### Module 2：Reflection 设计模式

让 LLM 反思自己的输出并改进。简单、易实现，常带来明显的性能提升；外部反馈（执行结果、检索、计数等）能让反思更强。

### Module 3：Tool Use（工具使用）

让 LLM 调用函数与工具，能力大幅扩展。**Code execution** 是其中特别重要的一个工具——一个工具相当于上千个工具。MCP 标准让接入工具的工程成本从 M×N 降到 M+N。

### Module 4：Evals 与 Error Analysis（讲者认为最实用的一块）

- 端到端 evals：客观/主观 × 有无每例 ground truth 的 2×2 矩阵。
- Error analysis：定位"是哪个组件错了"。
- 组件级 evals：选定组件后高效迭代。
- 改进组件的方法（prompt → 换模型 → 拆任务 → fine-tune）。
- 延迟与成本优化。
- 整体开发节奏：**Building ↔ Analyzing 来回切换**。

这一模块讲者认为是**未来长期受用最大**的内容。

### Module 5：高度自主 agent 的设计模式

- **Planning**：让 LLM 自己规划步骤；用 JSON / 代码表达计划；Code-as-Action 在多任务上优于 JSON 计划优于纯文本。
- **Multi-agent**：把任务拆给一个有分工的 agent 团队；通信模式从线性、经理调度、多层级，到 all-to-all。

## 写在最后

讲者两点提醒：

1. **职业层面**：他和很多团队面试 agentic AI 岗位时，考察的就是本课覆盖的这些技能。学完这门课在求职上是有现实价值的。
2. **使用层面**：把学到的技能**负责任地用起来**，去构建有意思的东西。
