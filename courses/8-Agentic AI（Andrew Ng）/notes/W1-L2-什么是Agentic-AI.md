# W1-L2 什么是 Agentic AI（What is Agentic AI）

> 原始字幕：`subtitles/W1-L2-what-is-agentic.vtt`

## 一、传统 LLM 使用方式 vs Agentic 工作流

### 1. 传统方式（非 agentic）
直接提示 LLM："请写一篇关于 X 主题的文章。"

这相当于要求一个人：
> 从第一个字到最后一个字，按线性顺序一次性写完，**且不允许使用退格键**。

- 人类不会这样写东西，LLM 也不擅长这样工作。
- 尽管有这种约束，LLM 的表现已经出人意料地好。

### 2. Agentic 工作流
把写文章拆成多步：
1. 先写一个**文章大纲**；
2. 判断是否需要**网络检索**；
3. 检索并下载网页；
4. 基于检索结果写**初稿**；
5. **阅读初稿**，找出需要修改或补充研究的部分；
6. **修订**草稿；
7. 继续迭代……

这更像人类真实的"**思考 → 研究 → 修订 → 再思考**"的循环过程。

**结论**：Agentic 工作流会耗时更久，但产出的质量**显著更好**。

## 二、Agentic AI 工作流的定义

> **Agentic AI 工作流 = 一个基于 LLM 的应用，执行多个步骤来完成一项任务的过程。**

在上面的例子里，可能的组成：
- 用一个 LLM 写大纲
- 用一个 LLM 决定向搜索引擎/搜索 API 提交哪些搜索词
- 把网页内容喂给 LLM，让它写初稿
- 再用一个 LLM 做反思（reflection），决定哪里需要改
- 可选地加入 **human in the loop**（人类审校关键事实）
- 最后再修订

## 三、贯穿课程的示例：研究智能体（Research Agent）

课程将带你构建一个研究智能体，例如输入研究主题：
> "How do I build a new rocket company to compete with SpaceX?"

它会：
1. 规划调研策略；
2. 调用 web 搜索引擎下载网页；
3. 综合、排序发现的结论；
4. 撰写大纲；
5. 让一个 **editor agent** 审核逻辑连贯性；
6. 最终生成一份结构完整的 markdown 报告（含前言、背景、发现等）。

通过多源下载 + 深度思考，产出比单次提示要**深刻得多**。

Andrew 在工作中构建过多种专用 research agent：
- 法律合规（conflict legal compliance）
- 医疗健康领域
- 商业产品调研

这些思路对你构建自己的定制研究智能体会**直接有用**。

## 四、Agentic 工作流的自主性光谱

一个常被讨论的问题：**智能体自主到什么程度？**

这节课展示的是一个相对复杂、高度自主的 Agentic AI 工作流，但还有许多**更简单却极具价值**的工作流。

> 下一节将讨论：agentic 工作流可以**有多自主**，以及它提供了一个怎样的框架帮你思考不同应用的构建难易度。
