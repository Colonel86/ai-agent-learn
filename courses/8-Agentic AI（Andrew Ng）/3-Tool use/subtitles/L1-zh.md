在本模块中，你将学习 LLM 的**工具使用（Tool Use）**——让 LLM 自主决定何时调用某个函数，以执行某个操作、获取某些信息或完成其他任务。

就像人类借助工具能做到徒手无法完成的事情一样，LLM 有了工具的加持，能力也会大幅提升。只不过我们给 LLM 的"工具"不是锤子或扳手，而是它可以请求调用的**函数**。

**工具使用的基本原理**

以"现在几点？"这个问题为例：一个几个月前训练好的模型无法知道当前时间，只能回答"抱歉，我无法获取当前时间"。但如果给它提供一个 `getCurrentTime` 函数，流程就变成：

1. 用户输入"现在几点？"
2. LLM 查看可用工具，决定调用 `getCurrentTime`
3. 函数返回当前时间，结果反馈给 LLM
4. LLM 输出"现在是下午 3:20"

关键在于：**是否调用工具由 LLM 自主决定**。同样的设置下，如果问"绿茶含多少咖啡因？"，LLM 不需要知道当前时间，就会直接回答，而不会调用 `getCurrentTime`。这与之前视频中开发者硬编码"始终在此步骤执行网络搜索"的方式不同——工具使用是 LLM 按需自主调用的。

**工具使用的更多应用场景**

- **餐厅推荐**：给 LLM 配备网络搜索工具，它可以自主搜索"Mountain View 附近的意大利餐厅"并返回结果
- **零售数据库查询**：给 LLM 配备数据库查询工具，它可以查找购买了白色太阳镜的客户记录
- **利率计算**：给 LLM 配备计算工具，或让它直接编写代码来计算复利结果

**多工具场景：日历助手**

更复杂的场景需要为 LLM 提供多个工具。以日历助手为例，用户说"帮我在周四找一个空闲时间，和 Alice 安排一个会议"，LLM 需要：

1. 调用 `checkCalendar`，查询周四的空闲时间
2. 选定时间段（如下午 3 点），调用 `makeAppointment`，发送日历邀请
3. 获得确认后，告知用户"已为你安排周四下午 3 点与 Alice 的会议"

可用工具还包括 `deleteAppointment`（取消现有日程），LLM 会根据实际需求自主选择调用哪些工具。
