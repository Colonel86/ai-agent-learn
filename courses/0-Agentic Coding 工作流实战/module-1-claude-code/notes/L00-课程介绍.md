## 一、AI 辅助编码的演化

```
LLM 偶发问答 → GitHub Copilot 自动补全 → 越来越自主的工具 → Claude Code
```

Claude Code 的"代次跃升"在于：
- 可以**几分钟到十几分钟**地自主工作完成一个任务，而不是只补一行。
- 开发者已经开始**并行编排多个 Claude 实例**在同一个 codebase 的不同部分。

> Andrew 的判断：很多人没系统学过最佳实践，导致没吃到这部分生产力红利。这门课的目的就是把这些实践讲透。

## 二、用好 Claude Code 的核心原则

**给清晰的 context**：
1. 指到相关文件（`@file` / `@folder`）
2. 清晰描述要做的功能
3. 用 MCP / 其他工具扩展 Claude Code 的能力

## 四、Claude Code 的架构（预告）

- 工具集很**小**：read / list / regex 等少数原语
- **不索引代码库**——不把代码上传到服务器、不做向量化
- 用 **agentic search**：让 Agent 自己读代码、做笔记到 `CLAUDE.md`
- 安全性收益：代码留在本地

> 架构师视角：这是一个"少而精"的工具集 + 强模型 + 智能调度的范式。它的反面（向量索引代码库）反而是把"复杂性"前置到了基础设施。Claude Code 把复杂性留给运行时的 Agent 推理，换来更小的攻击面和更新鲜的代码视图。
