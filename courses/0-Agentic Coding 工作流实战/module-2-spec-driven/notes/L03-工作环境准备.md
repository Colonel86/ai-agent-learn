## 一、SDD 与具体工具无关

> "SDD is a best practice that isn't tied to any specific IDE or coding agent."

可选组合（任意搭配）：
- WebStorm + Claude Code（本课）
- VS Code + Codex CLI
- Zed + 本地模型

---

## 二、本课所用栈

- **IDE**：WebStorm
- **Agent**：Claude Code
- **项目**：`AgentClinic`（TypeScript + Git）

---

## 三、几条上手原则

1. **从一开始就用 Git**：spec 也是要版本化的资产，和代码一起进 git。
2. **关注 Agent 的每个确认**：Agent 跑命令前会问你，**最终代码责任在你**。不要无脑放权。
3. **Unsafe mode 慎用**：可绕过确认，但要求你对 trade-off 完全理解。

---

## 四、心法

> "The ultimate responsibility for the code is yours."

后续每节都会示范一种与 Git 协同的 SDD 实践——spec 和 code 一起进版本控制，是 SDD 区别于 vibe coding 的关键证据。
