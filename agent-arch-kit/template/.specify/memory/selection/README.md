# 选型矩阵 · 挂载点说明

选型矩阵是"怎么选"的知识库（六层：模型 / 框架·编排 / 检索 / 工具·协议 / 观测·评估 / 记忆），
**全文不常驻上下文**——常驻的只有 constitution §2.1 的选型红线；细节按需加载（渐进披露）。

## 挂载方式（install 时二选一）

1. **vendored（推荐，默认）**：把矩阵源（`agent/skills/agent-selection/` 整包）拷贝到本仓
   `.claude/skills/selection-matrix/matrix/` 下，随本仓版本管理——离线可用、可 diff，
   但需要定期从源仓同步更新
2. **referenced**：只放指针（源仓路径 / URL），AI 用到时现查——始终最新，
   但跨仓引用在 CI / 无网环境会断

## AI 消费约定

- `/speckit.plan` 的「技术选型」小节按层查询本矩阵，引用条目编号（见 plan 模板 Selection Check）
- 引用格式：`矩阵/<层>/<条目或小节名>`，保证评审者能定位到具体依据
- 矩阵与现实冲突时（版本演进导致结论过期）：以实测为准，按 constitution §4 W1 回写修正矩阵，
  不要静默绕过

## 回写规则（constitution §4 W1）

- 回写条目注明：来源项目、日期、证据（评测数据 / 事故复盘链接）
- 只回写**可复用的结论**（"X 在 Y 场景下不行，因为 Z"），不回写项目流水账
