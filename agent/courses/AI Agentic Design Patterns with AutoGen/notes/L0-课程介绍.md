# L0 · 课程介绍：AutoGen——把多 agent 协作统一成"对话"

> 课程：AI Agentic Design Patterns with AutoGen（DeepLearning.AI × Microsoft × Penn State）
> 讲师：Chi Wang（Microsoft 首席研究员）& Qingyun Wu（Penn State 助理教授），两人都是 AutoGen 的 co-creator；Andrew Ng 主持开场。

## 一句话定位

AutoGen 是一个**多 agent 对话框架（multi-agent conversational framework）**：快速创建多个具有不同角色（role）、人设（persona）、任务和能力的 agent，用各种 agentic design patterns 组合它们去实现复杂 AI 应用——而所有模式的底层载体只有一个：**agent 之间的对话**。

开场动机案例（也是 L5/L6 的正课案例）：分析金融数据——写代码收集和分析股价、再把发现综合成报告，一个人要花几天做研究、编码、写作；多 agent 系统让你"创建并雇佣"一组为你工作的 agent（researcher、data collector、co-writer、executor），它们还能**迭代地 review、批评、改进结果**，直到达到你的标准。

## 核心概念

| 概念 | 含义 |
|---|---|
| ConversableAgent | AutoGen 的内置 agent 基类，把不同类型的 agent 统一在同一个编程抽象里（L1 主角） |
| 多 agent 对话范式 | 应用 = 一组 agent 之间的对话；编程工作 = 定义 agent + 编排它们怎么聊 |
| Sequential Chats | 顺序对话：一串两两对话按顺序执行，逐步完成任务清单（L2） |
| Nested Chat | 嵌套对话：agent 接到任务后，先调用一批"自己的 agent"内部迭代，再返回结果——你管理的 agent 也在管理它自己的 agent（L3/L4） |
| Reflection | 反思：agent 之间互相 review / critique / 改进产出（L3） |
| Tool Use | 工具使用：把用户自定义函数（如"判断某步棋是否合法"）交给 agent 调用（L4） |
| Coding & Code Execution | 没有预定义函数可给时，让 agent 自己写代码，校验后（可在沙箱里）执行来算出任务所需结果（L5） |
| Planning + Group Chat | 复杂任务需要规划——agent 要决定一个行动序列（取数、分析、写作、修订）；在群聊里加入 planning agent 并控制工作在 agent 间的流转顺序（L6） |

> **架构师视角**：AutoGen 的赌注是"**对话是多 agent 协作的通用抽象**"——reflection、tool use、planning 这些模式都不引入新机制，全部编译成"谁跟谁说话、说几轮、谁先说"。好处是心智模型极简、模式可自由嵌套组合；代价是控制流隐式地藏在对话编排里，不如显式图（LangGraph 的 state graph）那样可静态审查——这正是选型矩阵 11-design-patterns.md 里"对话驱动 vs 图驱动"的分野。

> **对比课程 08（Agentic AI 四大设计模式）**：课程 08 从概念层讲 Reflection / Tool Use / Planning / Multi-agent Collaboration 四大模式；本课程是它的"AutoGen 实现版"——四个模式逐一落地成代码（L3 反思、L4 工具、L6 规划、全程多 agent），且多出一层框架特有的**对话结构词汇**：two-agent chat、sequential chats、nested chat、group chat。

## 课程路线

| 课 | 主题 | 一句话预告 |
|---|---|---|
| L1 | 多 agent 对话与单口喜剧 | 构建第一个 ConversableAgent，编排两个 stand-up comedian agent（Cathy & Joe）互讲段子 |
| L2 | 顺序对话与客户入职 | Sequential Chats 模式：一串对话按步骤完成任务清单，以 customer onboarding 应用演示 |
| L3 | 反思与博客写作 | Reflection 框架 + nested chat：多个 reviewer agent 迭代打磨一篇 blogpost |
| L4 | 工具使用与对话象棋 | Tool Use：把用户自定义函数（棋步合法性检查）交给 agent，做一盘 conversational chess |
| L5 | 代码编写与财务分析 | Coding & Code Execution：agent 自己写代码并（沙箱）执行，完成财务数据分析 |
| L6 | 规划与股票报告 | Planning + Group Chat：加入 planning agent 控制工作流转，生成一份详细股票报告 |

（致谢：Microsoft 的 Eric Zhu、DeepLearning.AI 的 Diala Ezzeddine。）

> **记忆点（引出 L1）**：整门课只有一个原语——**对话**。L1 先把最小单元跑通：一个 ConversableAgent 怎么定义、`generate_reply` 为什么是无状态的、两个 agent 怎么用 `initiate_chat` 聊出一场有记忆、能自己停的单口喜剧。
