## 二、为什么需要 Agent 的长期记忆？

### 2.1 现状

> **越来越多的 AI 应用需要"跨时间持续运行"**——不再是一次性问答，而是长期陪伴用户。

### 2.2 典型场景：AI 个人助理

| 场景 | 没有长期记忆 | 有长期记忆 |
|------|--------------|-----------|
| 每次对话 | 像第一次见面的陌生人 | 越用越懂你 |
| 会议安排 | 每次都问偏好 | 自动按你的习惯安排 |
| 邮件回复 | 千篇一律 | 模仿你的语气和风格 |

> 💡 **Andrew 的观察**：助理类应用是长期记忆**最自然的落地场景**。
