# L3 guardrails 服务器依赖 —— 装在**单独**的 3.12 venv(.venv-guardrails)。
#
# ⚠️ 踩过的三个坑(都来自 0.5.3 这套旧 pin,已在此文件/启动步骤里规避):
#   1. guardrails 只支持 Python <3.13;本机默认 3.13,必须用 3.12 建 venv。
#   2. `guardrails start` 会自动 pip 安装 guardrails-api,但拼的版本号非法
#      ('guardrails-api>="^0.0.0a0"'),被现代 pip 拒绝 → 必须**预装** guardrails-api。
#   3. 新版 click(8.2+)与 guardrails 0.5.3 的 typer CLI 冲突,报
#      "Secondary flag is not valid for non-boolean flag" → 必须钉死 click<8.2。
#
# 装法:
#   /opt/homebrew/bin/python3.12 -m venv .venv-guardrails
#   .venv-guardrails/bin/pip install -r requirements-guardrails.txt
#
# 起服务器(server.env 里放 DEEPSEEK_API_KEY,供 litellm 路由到 DeepSeek):
#   .venv-guardrails/bin/guardrails start --config config_l3.py --env server.env --port 8000
guardrails-ai==0.5.3
guardrails-api==0.0.1
click<8.2
openai>=1.30
