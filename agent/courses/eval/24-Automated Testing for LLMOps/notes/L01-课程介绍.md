# L01 课程介绍（Introduction）

> 原始字幕：`subtitles/circleci_c1_01_en.vtt`、`subtitles/circleci_c1_06_en.vtt`
> 讲师：Rob Zuber（CircleCI CTO）+ Andrew Ng

---

## 一、课程目标

把**现代软件工程的测试实践**应用到 LLM 应用的开发与部署中——用自动化测试解放精力，专注于设计和构建应用的创造性部分。

最终成果：把 **per-commit 评估** 和 **pre-release 评估** 组合成一套**自动化测试套件**，并设计测试来**检测 LLM 响应中的幻觉（hallucination）**。

---

## 二、两类 LLM 评估（贯穿全课）

| | 规则评估 Rule-based | 模型评分评估 Model-graded |
|---|---|---|
| 方式 | 字符串 / 正则等模式匹配 | 用一个 LLM 评估另一个 LLM 的输出 |
| 速度成本 | 快、便宜 | 慢、贵 |
| 适用场景 | 有明确正确答案（如情感分类、有 ground-truth 标签） | 有多种好/坏输出（如生成文本内容） |
| 运行时机 | **每次 commit** 都跑，快速反馈 | **发布前** 跑，做更彻底的检验 |

---

## 三、自动化测试的两个节奏

- **per-commit**：你和队友每天可能提交多次代码 → 每次提交自动触发**规则评估**（快、便宜）。
- **pre-release**：每隔一两周发一次版 → 部署给用户前，自动跑更全面的 **模型评分评估**。

> 核心思想：**随着越来越接近发布，逐步提升对应用的信心。**

---

## 四、本节要点速记

- 课程把传统软件测试实践迁移到 LLM 应用，落点是「自动化 + CI 流水线」。
- 两类评估按「速度/成本」和「输出是否有唯一正确答案」来选择，并对应不同运行节奏。
- 课程的实战目标是构建一套能**检测幻觉**的自动化测试套件。
- 这是一个快速演进的新兴领域——evals + CI 的结合还在持续变化。
