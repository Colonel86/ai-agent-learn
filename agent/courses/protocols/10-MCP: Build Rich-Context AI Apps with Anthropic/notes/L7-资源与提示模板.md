# L7 资源与提示模板（Adding Resources & Prompt Features）

本讲在 server 端补上 `@mcp.resource(...)` 和 `@mcp.prompt()`，在 client 端补上 `@` 和 `/` 两套命令，把 MCP 三大原语完整跑通。

> 对应代码：`code/L7.ipynb` → 更新后的 `research_server.py` + `mcp_chatbot.py`

## Server 端：暴露 resources

资源是**只读数据**，类比 HTTP GET。本讲加两条：

### 静态 URI：列出主题目录

```python
@mcp.resource("papers://folders")
def get_available_folders() -> str:
    """List all available topic folders in the papers directory."""
    folders = []
    if os.path.exists(PAPER_DIR):
        for topic_dir in os.listdir(PAPER_DIR):
            topic_path = os.path.join(PAPER_DIR, topic_dir)
            if os.path.isdir(topic_path):
                papers_file = os.path.join(topic_path, "papers_info.json")
                if os.path.exists(papers_file):
                    folders.append(topic_dir)
    content = "# Available Topics\n\n"
    for folder in folders:
        content += f"- {folder}\n"
    content += f"\nUse @{folder} to access papers in that topic.\n"
    return content
```

URI 命名风格自由，但社区习惯 `scheme://path`（如 `papers://folders`）。

## Server 端：暴露 prompt template

```python
@mcp.prompt()
def generate_search_prompt(topic: str, num_papers: int = 5) -> str:
    """Generate a prompt for Claude to find and discuss academic papers on a specific topic."""
    return f"""Search for {num_papers} academic papers about '{topic}' using the search_papers tool.

    Follow these instructions:
    1. First, search for papers using search_papers(topic='{topic}', max_results={num_papers})
    2. For each paper found, extract: title / authors / publication date / key findings / contributions / methods / relevance
    3. Provide a comprehensive summary (themes, gaps, most impactful)
    4. Organize findings with headings and bullet points.
    """
```

FastMCP 自动用：

- 函数名 → prompt 名
- 函数参数 → prompt 参数（含默认值/必填判断）
- docstring → prompt 描述

> 价值：把"复杂 prompt engineering"做在 server 上，被很多用户复用——用户只填 `topic` 和 `num_papers`。

## Client 端改造

`MCP_ChatBot` 多了两类发现入口：

```python
self.available_prompts: List[dict] = []
# resources 一般在 chat_loop 里现场拉，不必预存
```

`connect_to_server` 在拉完 `list_tools` 后，再依次：

```python
try:
    prompts_resp = await session.list_prompts()
    for p in prompts_resp.prompts:
        self.available_prompts.append({
            "name": p.name,
            "description": p.description,
            "arguments": p.arguments,
        })
except Exception:
    pass  # 某些 server 没有 prompts

try:
    resources_resp = await session.list_resources()
    # 同样存下 URI
except Exception:
    pass
```

> 不是所有 server 都提供 prompts / resources，所以要兜异常。

## Chat loop 的命令语法

讲师设计了一套**自定义 UI 约定**（也可以换成你喜欢的）：

| 命令 | 含义 |
|---|---|
| `@folders` | 触发 `papers://folders` 资源 |
| `@<topic>` | 触发 `papers://<topic>` 资源 |
| `/prompts` | 列出所有可用 prompt 模板 |
| `/prompt <name> <arg1=value1>` | 用指定 prompt 模板 + 参数生成 prompt 并执行 |
| 其它任意输入 | 当作普通 query 走 LLM + tools |

> MCP 不规定 UI——展示与命令语法完全由 host/client 开发者自由设计。

### `get_resource(uri)`

```python
async def get_resource(self, uri):
    session = self._find_session_for_uri(uri)
    result = await session.read_resource(uri=uri)
    print(result.content)
```

### `list_prompts()`

打印每个 prompt 的名字、描述、所需参数。

### `execute_prompt(prompt_name, args)`

```python
result = await session.get_prompt(prompt_name, arguments=args)
prompt_text = "".join(m.content.text for m in result.messages)
await self.process_query(prompt_text)
```

把 server 渲染后的 prompt 文本喂回普通的 `process_query` 流程。

参数解析做一点字符串拆分：`topic=history num_papers=2` → `{"topic": "history", "num_papers": "2"}`。

## 实际操作

```bash
cd L7/mcp_project
source .venv/bin/activate
uv run mcp_chatbot.py
```

试一遍：

- `@folders` → 看到 server 返回的可用主题列表（如 `computers`、`math`）。
- `@computers` → 看到 computers 目录下 `papers_info.json` 的格式化摘要。
- `/prompts` → 列出 `generate_search_prompt`，以及 fetch server 自带的"fetch URL & convert to markdown" prompt。
- `/prompt generate_search_prompt topic=math num_papers=2` → server 把模板渲染好的 prompt 发回来，chatbot 把它当成用户 prompt 跑——会自动调 `search_papers` 工具、写文件，整个流程跑通。

执行完后 `@math` 就能看到刚刚写入的论文资源——**资源是动态的**。

## 这一讲的全景

| 原语 | server 装饰器 | client 发现 | client 调用 |
|---|---|---|---|
| Tool | `@mcp.tool()` | `list_tools()` | `call_tool(name, args)` |
| Resource | `@mcp.resource(uri)` | `list_resources()` / `list_resource_templates()` | `read_resource(uri)` |
| Prompt | `@mcp.prompt()` | `list_prompts()` | `get_prompt(name, args)` |

三者拼齐后，整个协议的能力面就完整了。
