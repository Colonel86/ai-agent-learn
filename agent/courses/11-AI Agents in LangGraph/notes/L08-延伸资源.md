---

## 一、本节目的

课程只覆盖了基础，Harrison 推荐以下资源用于**继续深入 agent 开发**。

---

## 二、推荐资源清单

### 1. LangChain 官方文档

- **LangChain Docs** —— LangChain 生态全貌的最佳起点
- 包含：
  - **LangChain Core 包** —— 基础抽象
  - **LangChain Community 包** —— 第三方集成（Tavily 就在这里）
  - **LangChain OpenAI 包** —— 独立的 partner 包
  - 其他大量集成
- LangChain 上层 API 对 agents / chains / retrieval 提供**高层入口**，适合想快速上手时用

### 2. LangServe —— 部署层

> 把 LangChain 应用一键变成 Web Server。

- 搭配大量 **templates** 使用
- 简化从原型到服务的过程

### 3. LangSmith —— 可观察性 & 调试

| 能力 | 用途 |
|---|---|
| **Debugging** | 从开发初期追踪 chain / agent 每一步 |
| **Production monitoring** | 上线后监控性能、成本、质量 |
| **Playground** | 交互式调试（课程中出现过） |

### 4. LangChain GitHub 仓库

- 大量 **cookbooks**
- 入门 **templates**
- 实战示例

### 5. LangGraph 仓库

深入的 LangGraph 资源：
- 完整参考文档（reference docs）
- 分步教程（tutorials）
- 针对具体问题的 how-to guides

### 6. DeepLearning.AI 前置 / 相关课程

| 课程 | 价值 |
|---|---|
| **Functions, Tools and Agents with LangChain** | 本课程的**强推荐前置课** |

### 7. LangChain Prompt Hub

社区贡献的优质 prompt 集合，查看 "业内人士怎么写提示词" 的灵感来源。

## 三、资源选择建议（按需组合）

| 你现在想做什么 | 推荐首选资源 |
|---|---|
| 了解生态全貌 | LangChain Docs 首页 |
| 深入 LangGraph 的具体特性 | LangGraph GitHub + 官方 tutorials |
| 把做好的 agent 上线 | LangServe + LangSmith |
| 线上监控 / 故障排查 | LangSmith |
| 找灵感 / 看例子 | LangChain GitHub cookbook + Prompt Hub |
| 补齐基础概念 | DeepLearning.AI 《Functions, Tools and Agents with LangChain》 |
