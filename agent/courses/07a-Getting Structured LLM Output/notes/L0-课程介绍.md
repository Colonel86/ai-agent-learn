# L0 课程介绍

## 一句话

自由文本适合聊天,但写软件需要能被程序可靠解析的结构化输出(通常是 JSON)——这门课系统讲三条获取结构化输出的路径,以及它们背后的原理。

## 课程脉络

讲师:Will Kurt(DotTxt 创始工程师)、Cameron Pfiffer(DotTxt 开发者关系)。

三条技术路线,课程按这个顺序展开:

1. **模型自带的结构化输出能力**(如 OpenAI Structured Outputs)——最容易上手,但绑定单一供应商,也有其局限(L2)
2. **重提示(re-prompting)库**——以 Instructor 为代表,靠"校验失败就重新问模型"逼近合法 JSON,跨供应商通用(L3)
3. **约束解码(constrained decoding)**——以 Outlines 为代表,直接在 token 生成层面掐掉不合法的选项,不重试就保证合法输出(L4 原理 / L5 超越 JSON)

贯穿全程的实战案例:一个读取社交媒体评论、判断情绪、决定是否需要人工客服介入的 Agent。最后一课展示约束解码不止能生成 JSON,还能生成电话号码、邮箱、CSV、甚至 ASCII 井字棋盘等任意可以用正则表达的格式。
