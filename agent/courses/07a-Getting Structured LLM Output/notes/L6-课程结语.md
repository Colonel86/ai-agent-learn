# L6 课程结语

课程回顾了三条获取结构化输出的路径——供应商原生 API(OpenAI Structured Outputs)、重提示库(Instructor)、约束解码(Outlines)——并强调结构化生成的能力远超 JSON,可覆盖任意能用正则表达的格式,甚至语法正确的代码。

## 给自己的落地清单

- 判断标准先问一句:**能不能拿到模型的 logits?** 能(自托管开源模型)→ 优先约束解码;不能(只能调闭源 API)→ 供应商原生 or Instructor 二选一,再看要不要跨供应商可移植性。
- Instructor/重提示类方案要把"重试成本"当真实的生产成本来算,尤其长 prompt、高频调用场景。
- 结构化输出不是只能做纯数据抽取,"结构化输出 + 思维链"完全可以结合(见 L5 的 GSM8K 例子),对 Agent 的"验证"环节(对照面试包 `01-agent-run-loop-and-orchestration` 的"验证"阶段)是个可直接复用的技巧。
- `Literal` + `Optional` 是把 LLM 输出"收窄成可编程数据"的两个最常用武器(见 L2 的 Mention 类)。

## 与已有资产的连接
