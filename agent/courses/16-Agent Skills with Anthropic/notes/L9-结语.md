# 结语：把 Skills 用起来

恭喜你走到这里。一路下来，你掌握了：

- 如何创建 Skill
- Skill 的最佳实践
- 在不同平台（Claude AI、Claude API、Claude Code、Agent SDK）上的实战

## 实操心法

### 从简到繁，渐进式扩展

> 创建 Skill 时，**先写最简单的 markdown 指令**，再按渐进式披露的思想逐步扩展。

不要一次性把所有信息塞进 `SKILL.md`。

### 在真实场景观察并迭代

观察 agent 在真实任务中如何使用你的 Skill，根据观察持续打磨。

### description 决定触发

`description` 必须**包含足够细节**，让 agent 能判断什么时候调用它。

### 直接和 Claude 对话开始

Claude 对 Skill 的运作机制非常熟悉。**你可以直接和它对话开始构建 Skill**，然后用 `skill-creator` 这个元 Skill 确保跟随最佳实践。
