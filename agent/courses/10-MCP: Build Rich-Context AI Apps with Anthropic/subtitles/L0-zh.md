**什么是 MCP？**

MCP（模型上下文协议，Model Context Protocol）是一个开放协议，基于客户端-服务器架构，标准化了 LLM 应用获取工具和数据资源的方式。它定义了 **MCP 客户端**（嵌入在你的 LLM 应用中）与 **MCP 服务端**（向应用暴露工具、数据资源和提示词模板）之间的通信方式。

MCP 由 Anthropic 于 2024 年 11 月发布，起源于扩展 Claude Desktop 能力的内部项目——最初是为了让它能与本地文件系统和外部系统交互。Anthropic 随后将协议规范公开，并向开源社区开放了开发权限。

MCP **与模型无关**，易于接入多种应用。

**MCP 解决了什么问题？**

以构建研究助手智能体为例：如果你希望它能访问 GitHub 仓库、读取 Google Drive 文档、将摘要保存到本地文件系统，过去需要为每个平台自己编写工具封装代码。有了 MCP，只需将智能体连接到对应的 MCP 服务端，工具定义和执行逻辑都由服务端处理，无需重复造轮子。
