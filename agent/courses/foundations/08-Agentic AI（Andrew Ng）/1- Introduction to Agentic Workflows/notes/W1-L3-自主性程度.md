# W1-L3 自主性程度（Degrees of Autonomy）

> 原始字幕：`subtitles/W1-L3-degrees-of-autonomy.vtt`

## 一、为什么用 "Agentic" 而不是 "Agent"

几年前 AI 社区在争论"什么才算真正的 agent"，这种二元争论毫无意义。Andrew 因此改用**形容词 agentic**：

> 承认系统可以在**不同程度**上是 agentic 的，把精力放在实际构建上，而不是纠结"这算不算真正的 agent"。

这个框架帮社区跳出了无谓的定义之争，专注做事。

## 二、自主性的光谱

智能体的自主性是**一个连续谱**，不是非黑即白。

### 1. 低自主性（Less Autonomous）
例：写一篇关于黑洞的文章。
- 一个简单 agent：**硬编码**调用 web 搜索 → 抓取网页 → 写文章。
- 所有步骤都是**确定的、由程序员预先规定**的线性序列。
- 效果尚可。

### 2. 高自主性（More Autonomous）
同一个任务：
- **LLM 自己决定**要做什么研究 → web 搜索？新闻？archive 论文？
- LLM 决定抓几个网页、要不要把 PDF 转文本；
- LLM 决定写完后是否反思并改进，是否再去抓更多资料；
- 最终产出文章。

**步骤顺序由 LLM 决定，而非程序员预先写死。**

### 3. 极高自主性（Highly Autonomous）
- 智能体自己决定整个步骤序列；
- 有些甚至能**写新的函数或创建新工具**，然后执行它们。

### 4. 半自主（Semi-Autonomous）
介于中间：
- 可以做一些决策、选择工具；
- 但**可用的工具通常是预先定义好的**。

## 四、实践启示

| 自主性 | 优点 | 代价 |
|---|---|---|
| 低自主 | 可控、稳定、可预测 | 灵活性差 |
| 高自主 | 能处理复杂情况 | 难控制、不可预测、研究前沿 |

**大量高价值应用都在低自主端**（很多企业已经在用）；高自主端当前多为研究探索，稳定性尚不足。

## 面试速答总结

**一句话**:这节把"自主性是光谱"讲透——**别争"算不算 agent"(无意义的二元之争),改用形容词 agentic,承认系统在不同程度上自主;架构师的活儿是按任务选"刚好够用"的那一档**。

### 面试回答骨架(问"agent 的自主性 / 怎么决定一个系统该多自主")

> 1. **先破二元论**:不要纠结"这算不算真 agent"。Andrew Ng 用形容词 **agentic** 正是为了跳出定义之争——系统是**程度问题**,不是 yes/no。
> 2. **给出光谱的四档**(由低到高,要能举例):
>    - **低自主**:步骤全部**硬编码**,程序员写死线性序列(搜索→抓取→写)。
>    - **半自主**:LLM 能做部分决策、选工具,但**可用工具是预定义的**。
>    - **高自主**:**步骤顺序由 LLM 自己决定**(搜什么、抓几个、要不要反思再补)。
>    - **极高自主**:LLM 自定整个流程,甚至**自己写新函数/造新工具**再执行。
> 3. **讲取舍(核心)**:低自主=可控/稳定/可预测,但不灵活;高自主=能处理复杂情况,但难控制/不可预测/仍属研究前沿。
> 4. **给判断结论**:**大量高价值应用都在低自主端**(企业已在用);高自主端当前稳定性不足、多为探索。所以**默认从低自主起步,复杂度证明值得了再往上加**。

### 为什么这是高分答法

- 先**破二元论**再给**光谱 + 取舍 + 默认立场**,展示的是判断力而非术语;
- "默认低自主、复杂度证明了再加"正好呼应 Anthropic"workflow 能解决就别上 agent"。

**一句话收尾**:自主性是连续谱,不是开关;**选刚好够用的最低自主度,把灵活性的代价(失控/不可测/高成本)留到任务真的需要时再付**。
