LangChain 是一个用于构建 LLM 应用的开源开发框架。我们提供两个不同的包：一个 Python 版，一个 JavaScript 版。

它们专注于组合性和模块化。拥有大量独立组件，这些组件既可以联合使用，也可以单独使用——这是其核心价值之一。

另一个核心价值是丰富的使用场景。通过"链"（chains）将这些模块化组件组合成更完整的端到端应用，使你能非常轻松地上手各种使用场景。

在本课程中，我们将涵盖 LangChain 的常用组件：

- **模型（Models）**：核心语言模型
- **提示词（Prompts）**：如何引导模型完成有用且有趣的任务
- **索引（Indexes）**：数据摄取方式，使数据能与模型结合
- **链（Chains）**：更完整的端到端使用场景
- **智能体（Agents）**：一种非常令人兴奋的端到端使用场景，将模型用作推理引擎
