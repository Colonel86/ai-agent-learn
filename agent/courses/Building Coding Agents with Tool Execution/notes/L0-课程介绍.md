# L0 · 课程介绍：让 Agent 写代码、执行代码来完成任务

> 课程：Building Coding Agents with Tool Execution（DeepLearning.AI × E2B）
> 讲师：Tereza Tizkova、Francesco Zuppichinni（E2B）；Andrew Ng 开场对谈。致谢名单：Jakub Dobry（E2B）、Esmaeil Gargari（DeepLearning.AI）。

## 一句话定位

**核心主张**：本课教你构建**把"生成并执行代码"当作完成工作的手段**的 Agent。大多数人给 LLM 预定义一小组 function 让它调；但如果转而允许 LLM/Agent **编写并执行任意 Python 代码**，它就拥有了每一个 Python 内置函数，甚至能要求安装常用 Python 包再调用其中的函数——**这极大地打开了 Agent 能做之事的空间**。

第二重收益是效率：常规 LLM tool use 面对稍复杂的任务，只能**逐次、串行地一个个发起 function call**；而会写代码的 Agent 可以直接写出一大块代码，**一次性高效执行一长串操作**——能力再上一个台阶。

**但代价同样明确**：在本地机器上运行 LLM 生成的代码是不安全的——万一代码做了不该做的事呢？Andrew 分享了两个真实事故：一个高度 agentic 的编码工具删掉了他团队成员的重要项目文件；另一个执行了有缺陷的数据库迁移、删掉了生产数据（幸好有备份）。因此安全运行生成代码的良好实践是：**在 sandbox 环境里跑，让代码执行与你的系统隔离**。

> **对比 0-action-paradigm.md（行动范式层）**：Andrew 这段开场白就是选型矩阵最上游那个分叉的原文注脚——① function/tool calling（预定义离散工具，可校验可审计，但工具多/要控制流时 round-trip 多）vs ② CodeAct（模型直接写代码当动作，一块代码搞定组合与循环，但**必须沙箱**）。本课整门课就是把 ② 这一档从"取舍表里的一行"展开成完整工程实践：怎么写 loop、怎么管 context、怎么选执行环境。

> **架构师视角**：注意 Andrew 给出的两个事故案例的共性——出事的都不是"模型能力不够"，而是**执行面没有隔离**（blast radius 直达本机文件系统和生产数据库）。这印证 7-safety-guardrails.md 的判断：选了 CodeAct，沙箱不是可选优化而是**前置成本**；评估 CodeAct 方案时先问"隔离层在哪"，再谈能力收益。

## 核心概念/类比

| 概念 | 类比 | 一句话 |
|---|---|---|
| Coding agent | 会自己动手写脚本的助理 | 把"生成 + 执行代码"作为完成任务的手段的 Agent |
| 预定义 function set | 只给助理一盒固定工具 | 常规 tool use：LLM 只能调你事先定义的小工具集 |
| 任意代码执行 | 给助理整间五金店 + 采购权 | 全部 Python 内置函数 + 可安装包，能力空间大开 |
| 批量代码 vs 逐次调用 | 一张完整购物清单 vs 每买一件跑一趟 | 一大块代码一次执行长序列操作，省掉逐次 function call 的往返 |
| Sandbox | 化学实验的通风橱 | 生成代码在隔离环境中执行，出事不伤宿主系统 |

## 课程路线

| 课 | 一句话预告 |
|---|---|
| L1 | 拆解 AI coding agent 到底是什么、与其他 AI Agent 有何不同：LLM 如何逐步推理、决定调哪个工具、执行代码并用结果规划下一步 |
| L2 | （lab）动手构建自己的 Agent：能运行 Python 代码、读写文件、在任务上反复迭代直到得出最终答案；讨论 context window 管理、错误处理与重试 |
| L3 | 理解 Agent 如何思考与行动之后，探索不同执行环境：local execution、containers、安全沙箱化的 microVM，并学会按 use case 选对环境 |
| L4 | （lab）创建与管理 sandbox：远程运行多语言代码、与 sandbox 文件系统交互——Agent 由此能使用上传的数据集、保存输出，甚至创建并托管小型 web 应用 |
| L5 | （lab）构建 data analyst agent：用 pandas 探索 CSV 文件并生成清晰的可视化 |
| L6 | （lab）构建 full-stack agent：编辑多个文件、在 sandbox 里搭出可运行的 Next.js web 应用；用 runtime summarization 管理长 context，让 Agent 在大型多文件项目中保持专注 |
| L7 | 动手项目介绍 + 课程结语 |
