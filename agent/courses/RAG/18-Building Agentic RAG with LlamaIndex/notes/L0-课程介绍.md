# 课程介绍

欢迎来到《用 LlamaIndex 构建智能体式 RAG》（Building Agentic RAG with LlamaIndex）课程。

本课讲师是 **LlamaIndex 联合创始人兼 CEO Jerry Liu**，由 Andrew Ng 在 DeepLearning.AI 上引介开场。

## 什么是 Agentic RAG？

**Agentic RAG（智能体式检索增强生成）** 是一个用来构建"研究型智能体"的框架——它让 LLM 不只是把检索到的文本拼进提示词里回答，而是能够**对你的数据进行推理与决策**。

举个例子：你手上有一组研究论文，想就某个话题问一个问题，并希望得到一份对这些论文观点的综合总结。这样的需求往往需要多步处理：

- 先从某篇论文里识别出一个主题
- 这个主题又会改变后续步骤——例如需要从其他论文中检索关于该主题的更多信息
- 最终再综合多源信息形成回答

对比之下，**标准 RAG 流水线**虽然非常流行，但更适合在小规模文档上回答简单问题：检索一些上下文 → 塞进提示词 → 调用一次 LLM → 拿到回答。它本质上是**一次性前向通过（single forward pass）**，缺乏推理与多步规划能力。

本课程会把"和你的数据对话"这件事推到一个新的层次——构建一个**自主研究智能体（autonomous research agent）**。

## 课程主线：从简单到复杂的推理能力

Jerry 把课程内容拆解成一条循序渐进的能力链：

1. **路由（Routing）**：让 LLM 做决策，把请求路由到多个工具中合适的那个。
2. **工具调用（Tool Use）**：为智能体定义一个接口，让它不仅能选择工具，还能为该工具**生成正确的参数**。
3. **带工具的多步推理（Multi-step Reasoning with Tool Use）**：让 LLM 在一组工具上执行多步推理，并在整个过程中**保持记忆（memory）**。

围绕这条主线，你还会学到如何**有效地与智能体交互**，进行细粒度的控制与监督，包括：

- **可调试性（Debuggability）**：能够单步跟踪智能体的执行，看清它每一步在干什么，并据此改进它。
- **可引导性（Steerability）**：在中间步骤中允许用户注入引导。比如你看到它在检索错误的文档，就像一位资深主管给新员工"轻推一把"那样，给它一条提示去看另一份文档——这往往能带来显著更好的表现。

## 四节课的结构

- **第 1 课（Lesson 1）**：在**单一文档**上构建一个**路由器（Router）**，让它既能做问答，又能做摘要。
- **第 2 课**：工具调用——让 LLM 选择函数并推断参数。
- **第 3 课**：构建**智能体推理循环（Agent Reasoning Loop）**，支持复杂多步问题与上下文记忆。
- **第 4 课**：把能力扩展到**多文档智能体（Multi-Document Agent）**。
