# W1-L3 自主性程度（Degrees of Autonomy）

> 原始字幕：`subtitles/W1-L3-degrees-of-autonomy.vtt`

## 一、为什么用 "Agentic" 而不是 "Agent"

几年前 AI 社区在争论"什么才算真正的 agent"，这种二元争论毫无意义。Andrew 因此改用**形容词 agentic**：

> 承认系统可以在**不同程度**上是 agentic 的，把精力放在实际构建上，而不是纠结"这算不算真正的 agent"。

这个框架帮社区跳出了无谓的定义之争，专注做事。

## 二、自主性的光谱

智能体的自主性是**一个连续谱**，不是非黑即白。

### 1. 低自主性（Less Autonomous）
例：写一篇关于黑洞的文章。
- 一个简单 agent：**硬编码**调用 web 搜索 → 抓取网页 → 写文章。
- 所有步骤都是**确定的、由程序员预先规定**的线性序列。
- 效果尚可。

### 2. 高自主性（More Autonomous）
同一个任务：
- **LLM 自己决定**要做什么研究 → web 搜索？新闻？archive 论文？
- LLM 决定抓几个网页、要不要把 PDF 转文本；
- LLM 决定写完后是否反思并改进，是否再去抓更多资料；
- 最终产出文章。

**步骤顺序由 LLM 决定，而非程序员预先写死。**

### 3. 极高自主性（Highly Autonomous）
- 智能体自己决定整个步骤序列；
- 有些甚至能**写新的函数或创建新工具**，然后执行它们。

### 4. 半自主（Semi-Autonomous）
介于中间：
- 可以做一些决策、选择工具；
- 但**可用的工具通常是预先定义好的**。

## 三、课程的记号约定

| 🔴 红色 | **用户输入**（query、文档等） |

## 四、实践启示

| 自主性 | 优点 | 代价 |
|---|---|---|
| 低自主 | 可控、稳定、可预测 | 灵活性差 |
| 高自主 | 能处理复杂情况 | 难控制、不可预测、研究前沿 |

**大量高价值应用都在低自主端**（很多企业已经在用）；高自主端当前多为研究探索，稳定性尚不足。
