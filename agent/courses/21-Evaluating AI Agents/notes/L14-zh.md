# L14：课程小结与展望

恭喜完成本课程。

## 你学到了什么

围绕一个**基于代码的智能体**，你完整走过了一遍现代智能体工程的核心环节：

- **Trace（追踪）**：用 OpenTelemetry + OpenInference + Arize Phoenix 给智能体的每一步打点
- **Evaluate（评估）**：Code-based、LLM-as-a-judge、人工标注三类方法的取舍与组合
- **Improve（改进）**：用 Phoenix Experiments 把所有评估器排成 HUD，做"苹果对苹果"对比，驱动迭代
- **Productionize（生产化）**：把同一套机制延伸到生产监控、CI/CD 与自我改进飞轮

## 接下来

- 把这套方法迁移到你自己的智能体框架——LangGraph、CrewAI、OpenAI Agents SDK、AutoGen 等都适用
- 关注课程**附加资源（Resource Section）**：进一步阅读 Arize 文档、Phoenix 教程与 OpenInference 规范
- 围绕你的真实业务**搭一份 Golden Dataset**，让评估真正成为你的开发引擎

期待看到你用这些方法构建出什么。
