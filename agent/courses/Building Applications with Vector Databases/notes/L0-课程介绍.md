# L0 · 课程介绍：向量数据库不止 RAG——六大应用全景

> 课程：Building Applications with Vector Databases（DeepLearning.AI × Pinecone）
> 讲师：Tim Tully（Pinecone 董事会成员，前 Splunk CTO、前 Yahoo 工程 VP）；开场对谈 Andrew Ng。
> 本课定位：向量数据库已是 LLM 应用（尤其 RAG）的基础设施，但它的用途**远比大众认知的宽**。这门短课用六个可动手的应用，把"能快速取回相似向量"这一个能力铺开成一整片应用空间。

## 课程主线：一个能力，六种用法

向量数据库的本质动作只有一个——**存入一批向量，用一个查询向量取回与之最相似的若干条**。RAG 只是这个动作最出名的一种用法（取回相关文档喂给 LLM 生成回答）；但同样的"找相似"能力，换个数据形态就变成了图像搜索、异常检测、推荐。课程把这一点作为总纲：

```
                     ┌─ 存入向量集合 ─┐
   任意数据 ──embedding──►│  Vector DB   │──query 向量──► 取回 Top-K 最相似
                     └───────────────┘
                              │
   同一个「找相似」能力，按数据形态派生出六大应用：
   ①语义搜索  ②RAG  ③推荐  ④混合搜索  ⑤图像相似  ⑥异常检测
```

## 六大应用与数据集

课程按下表顺序逐个动手，每个应用配一份真实数据集：

| # | 应用 | 数据集 | 一句话 |
|---|---|---|---|
| 1 | 语义搜索 Semantic Search | Quora 文本 | 全课地基：文本相似检索，后续每课都用到 |
| 2 | RAG | Wikipedia 文章 | 取回相关文档 + prompt engineering → LLM 写出成文回答 |
| 3 | 推荐系统 Recommender | 新闻文章（all-the-news） | 按标题 / 按正文两种粒度做内容推荐 |
| 4 | 混合搜索 Hybrid Search | 时尚商品（图 + 文） | dense + sparse 同时检索，用 alpha 旋钮调权重 |
| 5 | 图像相似 Image Similarity | 人脸图像（英国王室） | 用向量判断孩子更像父母哪一方 |
| 6 | 异常检测 Anomaly Detection | 服务器网络日志（结构化） | 新条目找不到相似项 → 疑似异常 |

> 注：本笔记覆盖前半部分。素材字幕的正课从第 2 课 RAG 起（语义搜索作为地基在口播里被反复引用），因此本批笔记按 **L1=RAG、L2=推荐、L3=混合搜索** 编号。图像相似与异常检测在后半部分。

## 贯穿全课的三个不变量

不管做哪个应用，Pinecone 的用法都收敛到同一套骨架，先在这里立住，后面每课都在复用：

1. **一条 Pinecone 记录 = 三元组 `(id, values, metadata)`**：`id` 唯一标识，`values` 是向量本体（一串浮点数），`metadata` 是随行的原始数据（文章正文、商品字段、图片指针）。
2. **同一套读写流程**：连接 Pinecone → 建/删 index → embedding → 分批 upsert（100–500 一批，讲师惯用 200）→ `describe_index_stats` 核对条数 → `query(top_k, include_metadata=True)`。
3. **应用差异只在两处**：喂什么数据（文本 / 图像 / 结构化日志）、以及查询后怎么用回来的结果（直接看 / 交给 LLM 生成 / 调 alpha 混合）。

> **架构师视角**：这门课的真正价值不是"教会你调 Pinecone SDK"，而是**把"向量相似检索"从 RAG 的附属组件，重新定位成一个通用原语**。当你在做架构决策时，看到"找相似""去重""离群""按内容推荐"这类需求，都应该条件反射地想到向量库，而不是各自造轮子。六大应用就是这个原语的六个投影。

## 本课要点

| 要点 | 一句话 |
|---|---|
| 核心能力 | 存向量 + 取 Top-K 相似，一个动作派生六种应用 |
| 记录模型 | `(id, values, metadata)` 三元组贯穿全课 |
| 流程骨架 | 连接→建索引→embedding→分批 upsert→query，六课都一样 |
| 认知升级 | 向量库不是 RAG 专用件，而是"找相似"的通用基础设施 |

> **记忆点（引出 L1）**：向量库最出名的用法仍是 RAG。L1 就从最经典的 RAG 落地开始——用 Wikipedia 数据在 Pinecone 里检索，再把取回的散碎文档交给 OpenAI 做 prompt engineering，生成一篇通顺成文的回答，把"检索 + 生成"两步完整跑通一遍。
